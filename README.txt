SHIELD 1.1 - 프로젝트 파일

빌드: PowerShell에서 이 폴더를 연 뒤 .\build.ps1 실행

MSI에 포함되는 사용자 설명서:
  docs\03_사용_방법.txt

설치 후 사용자는 시작 메뉴 > Shield > Shield 사용 설명서에서 안내문을 열 수 있고,
설치 폴더의 "사용 방법.txt"에서도 읽을 수 있습니다.

폴더 구성 및 빌드 상세:
  docs\01_프로젝트_설명.txt
  docs\02_빌드_방법.txt

빌드 도구: WiX 5.0.2를 .config\dotnet-tools.json에 고정했습니다. 전역 WiX 설치는 변경하지 않습니다.
Cargo.toml의 [workspace]가 프로젝트를 독립 워크스페이스로 설정합니다.

1.1 변경 사항 (요약)
- UI: 탭(암호화/복호화/비밀번호 변경/디스크 정리/사용법), 단계별 입력, 부족한 입력 실시간 안내,
  단계·진행률·속도·남은 시간이 보이는 진행 표시줄, 아이콘 추가, 작업 표시줄 고정 가능
- 보안: 기본 PIM 12(1.0 파일 자동 호환), 마우스 엔트로피 1024비트 보수적 수집, 프로세스 DACL 우회 차단,
  비밀번호 변경 시 DEK 일치 확인, 압축 항목 검증 강화, 외부 명령 절대 경로 실행
- 디스크: TRIM만 실행하는 기능 추가, 여유 공간 덮어쓰기는 선택 사항으로 변경
- 이름: 같은 이름이 있으면 "(decrypted)"를 붙임
- 버그: 1.0에서 폴더 .shd 복호화가 실패하던 문제 수정
- 설치: 주의사항/사용법 화면, 설치 진행률, 설치 후 실행, 기존 버전 자동 업그레이드
