SHIELD 2.1.0 - 사용 방법 및 안전 안내
===================================

이 문서는 시작 메뉴의 "Shield 사용 설명서"와 설치 폴더의 "사용 방법.txt"로 다시 열 수 있습니다.
두 창 모두 '사용법' 탭에 같은 핵심 내용이 있습니다.

0. 설치와 업그레이드
--------------------
- Shield.msi 첫 화면의 주의사항을 읽고 확인란을 선택한 뒤 [설치]를 누릅니다.
- 이전 버전이 설치되어 있으면 자동으로 업그레이드합니다.
- 중요: Shield 2.x는 1.x에서 만든 .shd 파일을 열지 않습니다. 업그레이드 전에 1.x로 모두 복호화해 두고,
  설치 후 다시 암호화하세요.
- 배포 파일에 GPG 서명(.sig)이 함께 있으면 VERIFY.txt의 방법으로 먼저 검증하세요.
  Authenticode 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
- 설치 없이 쓰는 포터블 실행 파일(Shield_v{버전}_portable.exe)이 함께 배포될 수 있습니다. 14절을 보세요.

1. 두 개의 창
-------------
- "Shield" (암호화 창): 암호화 / 복호화 / 비밀번호·키 교체 / 디스크 정리 / 알고리즘·정보 / 설정 / 사용법 탭.
- "Shield 파일 관리자": 폴더를 탐색하고 .shd 컨테이너를 열어 내용 보기·일부 추출·파일 추가·항목 삭제를 합니다.
- 각 창의 오른쪽 위 버튼으로 다른 창을 열 수 있습니다.
- 기본 창 크기는 1040x700, 최소 크기는 800x560입니다. 주요 화면은 기본 크기에서 스크롤 없이 보이도록 했고,
  창이 좁아지면 두 열 배치가 한 열로 바뀝니다. 고급 옵션은 접혀 있습니다.
- 위쪽 탭과 아래쪽 실행 버튼·진행 표시줄은 항상 보이고, 가운데 부분만 스크롤됩니다.
- 아래쪽 진행 표시줄: 단계, 진행률, 속도, 남은 시간, 경과 시간, [취소]. 작업 중에는 창을 닫을 수 없습니다.
  (원본 파쇄·TRIM·교체 단계는 취소할 수 없습니다)

2. 암호화 (암호화 창)
---------------------
1) [파일 선택…]/[폴더 선택…]을 누르거나 창에 끌어다 놓습니다.
2) 비밀번호를 두 번 입력합니다. 강도 표시는 흔한 패턴을 반영한 '대략적 추정'입니다.
   설정에서 허용했다면 칸 옆 [보기]로 입력한 글자를 잠시 볼 수 있습니다(보는 동안은 화면 라이브러리가
   글자를 내부에 복사해 둘 수 있습니다).
3) PIM은 권장 기본값(12)을 그대로 두면 됩니다. 설정에서 기본값을 바꿨다면 그 값이 표시됩니다.
4) 필요하면 키 파일을 추가하거나 새로 생성합니다.
5) 압축 강도: 자동(권장) / 빠름(Zstandard) / 균형 / 최대.
6) [암호화 시작] → 목록 확정 → 압축 → 암호화 → 복원 검증.

- 원본 옆에 "이름.shd"로 저장하며, 같은 이름이 있으면 "이름 (2).shd"처럼 번호를 붙입니다. 덮어쓰지 않습니다.
- 복원 검증: 만든 파일을 다시 열어 모든 청크를 인증하고, 전부 풀어 원본과 크기·SHA3-512를 비교합니다.
  하나라도 다르면 결과를 지우고 원본은 그대로 둡니다.
- 폴더 안의 바로가기/심볼릭 링크(정션)와 특수 파일은 따라가거나 포함하지 않습니다(완료 메시지에 개수 표시).
- 비밀번호가 짧거나(12자 미만) 흔한 패턴이어서 약하다고 판단되면, 이유를 보여 주는 확인 창이 뜹니다.
  기본 버튼은 [취소]이고 Esc도 취소입니다. 키 파일 없이 비밀번호만 쓰면 12자 이상(기본보다 낮은 PIM이면
  20자 이상)이어야 합니다.
- 비밀번호 칸은 최대 256바이트입니다. 넘으면 오류 표시가 나오며, 잘라서 진행하지 않고 거부합니다.
- 붙여넣은 비밀번호는 클립보드에 남습니다. 칸 아래 [클립보드 비우기]를 누르세요.
- 오른쪽 열에 "마우스 엔트로피" 막대가 보입니다. 14절의 설명을 보세요. 이것을 기다릴 필요는 없습니다.

3. 키 파일
----------
- "새 키 파일 생성…": 크기 1~1024 KiB(기본 1 KiB). 운영체제 난수와(켜 둔 경우) 마우스 엔트로피를 SHAKE256으로
  결합해 만들고, 만들 때부터 사용자 전용 권한으로 저장합니다. 크기를 늘려도 실효 강도의 상한은 지문 길이
  (512비트)입니다.
- 생성은 마우스 엔트로피 수집을 기다리지 않습니다. 마우스 엔트로피는 키 파일만을 위한 것이 아니라
  프로그램 전체의 난수 생성에 보조로 섞이는 것이며, 강도는 OS 난수가 보장합니다.
- 키 파일은 SHA3-512 지문으로 쓰입니다. 빈 파일, 한 가지 바이트로만 된 파일, 같은 파일 중복은 거부합니다.
- 암호화 대상 안에 있는 키 파일은 쓸 수 없습니다(파쇄되면 영영 열 수 없게 되므로).
- 비밀번호 없이 키 파일만 쓰려면 확인란을 체크해야 합니다. 비밀번호와 함께 쓰는 것을 권장합니다.
- 키 파일은 수정하지 말고 다른 곳에 백업하세요. 1바이트만 바뀌어도 쓸 수 없습니다.

4. PIM
------
- Argon2id(메모리 256 MiB, 병렬도 4)의 반복 횟수 = 3 + PIM. 기본 PIM 12 → 반복 15.
- 0~64를 직접 지정할 수 있습니다. 파일에 저장되지 않으므로 바꿨다면 반드시 기록하세요.
- 키 유도에 256 MiB 메모리가 필요합니다. 메모리 잠금에 실패하면 화면에 경고가 표시됩니다.

5. 복호화 (암호화 창)
---------------------
1) .shd 파일을 선택하고 같은 비밀번호·PIM·키 파일을 넣은 뒤 [복호화 시작].
2) 본문 전체를 먼저 인증한 뒤에만 풉니다. 사용자 전용 임시 폴더에 풀고 경로·크기 제한을 검사한 뒤
   .shd 옆으로 옮깁니다. 같은 이름이 있으면 "(decrypted)"를 붙입니다.
- 압축 안의 목록(파일 수·폴더 수·전체 크기)이 파일에 인증되어 적힌 값과 다르면 변조로 보고 중단합니다.
- .shd가 인터넷에서 받은 파일이면, 풀려 나온 파일마다 같은 "인터넷에서 받은 파일" 표시가 붙습니다
  (SmartScreen·Office 보호 보기가 동작하도록). 설정의 엄격 모드를 켜면 표시를 붙이지 못할 때 결과를 지웁니다.
- 틀린 비밀번호·PIM·키 파일, 손상, Shield 파일이 아님은 모두 같은 메시지로 표시됩니다.

6. 파일 관리자와 "SHIELD에서 열기"
---------------------------------
- 주소 칸에 경로를 넣고 Enter, 폴더 두 번 클릭으로 이동, [위로], [드라이브], 이름 필터.
- 클릭 = 선택, Ctrl+클릭 = 여러 개 선택, 두 번 클릭 = 열기. [암호화…]는 선택한 항목으로 암호화 창을 엽니다.
- 수정 날짜는 "YYYY-MM-DD HH:MM" 고정 폭으로 보이며(설정에서 형식·초 표시 선택), 열 머리글 경계를 끌어
  너비를 조절할 수 있습니다. 창이 좁아지면 이름이 먼저 줄어들고, 마우스를 올리면 전체 이름이 보입니다.
- .shd를 두 번 클릭하거나 끌어다 놓거나 우클릭 "SHIELD에서 열기" → 비밀번호·PIM·키 파일 입력 → [열기].
- 열 때는 키 슬롯·메타데이터와 7z 목록이 든 청크만 인증·복호화합니다. 평문 파일은 만들지 않습니다.
  목록을 읽은 직후 키와 비밀번호는 메모리에서 지우고, 목록만 남깁니다.
- 열린 뒤에는 검사·추출·추가·삭제 등 키가 필요한 작업을 할 때마다 비밀번호(와 PIM·키 파일)를 다시 묻습니다.
  "이번 세션 동안 기억" 같은 기능은 없습니다.
- [파일] 탭: 내부 폴더를 두 번 클릭해 이동. 이름·크기·수정 시각, 선택 개수·용량 표시.
- [정보] 탭: 형식 버전, 알고리즘, KDF(메모리·병렬도·반복), 해시, 압축 방식·레벨·사전, 암호문·실제·패딩 크기,
  청크 수, 파일·폴더 수, 총 해제 크기, 검사 상태(본문 전체는 검사 전까지 '미검사').
- [선택 항목 추출…]: 고른 항목만 꺼냅니다. 읽는 청크마다 인증하며, 실패하면 부분 결과를 지우고 이미 옮긴
  파일도 되돌립니다.
- [전체 추출…]: 복호화와 같은 방식(본문 전체 인증 후 해제)입니다.
- [파일 추가…]/[폴더 추가…]/끌어다 놓기: 보고 있는 폴더에 추가합니다. 기존 항목과 합쳐 새 키로 다시 암호화하고
  모든 항목을 SHA3-512로 검증한 뒤 원자적으로 교체합니다. 같은 이름이 있으면 덮어쓸지 묻습니다.
  열어 둔 사이에 .shd가 바뀌었으면 교체하지 않습니다. "추가한 원본 파쇄"를 켜면 확인 후 7회 덮어써 삭제합니다.
- [선택 항목 삭제…]: 고른 항목을 컨테이너에서 뺍니다. 설정의 "삭제 전에 확인"이 켜져 있으면 먼저 묻고,
  삭제도 전체를 다시 암호화·검증한 뒤 교체합니다.
- [본문 전체 검사]: 모든 청크의 인증 태그를 확인합니다(취소 가능).
- 5분 동안 조작이 없거나 [닫기]·창 닫기 시 열린 컨테이너의 목록을 메모리에서 지웁니다.
- 같은 컨테이너를 다른 Shield 창이 바꾸는 중이면 "다른 작업이 사용 중"이라고 나옵니다. 3초 기다려도
  안 되면 [다시 시도]를 누르세요.
- 한계: 화면에 그린 파일 이름은 GUI 라이브러리가 내부에 복사할 수 있으며 완전히 지울 수 없습니다.

7. 비밀번호·키 교체 (암호화 창)
-------------------------------
- 맨 위에 "방식" 두 가지가 가로로 나란히 있고, 고른 방식의 설명만 아래에 보입니다.
- 비밀번호만 변경 (빠름): 데이터 키를 새 자격 증명으로 다시 감쌉니다. 새 슬롯을 다시 열어 같은 키인지
  확인한 다음 이전 슬롯을 7회 덮어씁니다.
- 전체 키 교체: 새 데이터 키·솔트·nonce·패딩으로 전체를 다시 암호화하고 검증한 뒤 원자적으로 교체합니다.
  데이터 키 유출이 의심될 때 씁니다. 파일 크기만큼의 시간과 여유 공간이 필요합니다.
- 어느 쪽이든 이전에 만든 백업본·클라우드 버전 기록·섀도 복사본은 이전 비밀번호로 계속 열립니다.

8. 원본 파쇄 (암호화 탭 ⑤)
--------------------------
- "복구할 수 없음을 이해했습니다"를 체크해야 켜집니다.
- 목록 확정 시점의 파일만, 크기·수정 시각·파일 ID가 그대로일 때만 덮어쓴 뒤 삭제합니다.
  작업 중 바뀌거나 새로 생긴 파일, 하드 링크된 파일, 링크(정션)는 건드리지 않고 완료 메시지에 알립니다.
- 파일에 NTFS 숨은 스트림(ADS)이 있으면 멈추고, 포함해서 파쇄할지 묻습니다(비밀번호를 다시 입력). 다운로드
  표시만 있는 파일은 함께 덮어쓰고 결과 메시지에 적습니다.
- 덮어쓰기: HDD/모름 7회, SSD 1회("SSD여도 7회" 선택 가능). 이후 TRIM(기본 켜짐), 여유 공간 덮어쓰기(선택).
- 파쇄·TRIM·여유 공간 덮어쓰기가 실패하면 성공으로 표시하지 않고 오류(빨간색)로 알립니다.
  이때 만들어진 .shd는 그대로 남습니다.
- SSD·USB·볼륨 섀도 복사본·클라우드 동기화 폴더에서는 물리적 삭제를 보장할 수 없습니다.

9. 디스크 정리 탭
-----------------
- TRIM 실행(권장, 빠름, 관리자 확인 창이 뜰 수 있음, HDD 미지원).
- 여유 공간 덮어쓰기(선택): cipher /w로 3회. 오래 걸리고 SSD 수명을 소모합니다. 취소 가능.

10. 비정상 종료 후
------------------
- 작업 중 강제 종료되면 평문이 든 임시 폴더(.shd_…_x)가 남을 수 있습니다. 다음 실행 때 창 위쪽에 알림이 뜨며
  [지금 덮어쓰고 삭제]로 정리할 수 있습니다. 다른 Shield 창이 쓰고 있는 폴더는 알리지 않습니다.
- 임시 폴더 기록 파일이 손상되었으면 오류로 알리고 "복구 검사"를 제안합니다. 기록이 없다고 해서 남은 폴더가
  없다고 가정하지 않습니다.
- 임시 폴더의 덮어쓰기나 삭제가 실패하면 기록을 남겨 두어 다음 실행 때 다시 알립니다.
- 암호화된 임시 파일(.shd_….tmp)과 미완성 결과(.shd_….part)는 키가 사라져 읽을 수 없으며 직접 지워도 됩니다.

11. 중요한 안전 안내
--------------------
- 비밀번호, PIM, 키 파일 중 하나라도 잃어버리면 누구도 복호화할 수 없습니다.
- 원본 파쇄 전 반드시 복사본으로 복호화를 시험하세요.
- 메모리 잠금, zeroize, 프로세스 보호는 최선의 노력입니다. 같은 사용자 권한의 악성 프로그램, 관리자 권한,
  커널, 물리적 접근은 막지 못합니다. (프로세스 보호 때문에 작업 관리자에서 일반 권한으로 Shield를 강제
  종료하지 못할 수 있습니다. 창을 닫아 종료하세요.)
- 암호문 크기로 원본 크기의 대략적 범위는 알 수 있습니다(패딩은 일부만 가림).
- 히든 볼륨이나 부인 가능 저장 기능은 없습니다.

12. 설정 탭
-----------
암호화 창의 [설정] 탭에서 아래 항목을 바꿀 수 있고, 바꾼 값은 바로 적용됩니다.
분류: 일반 / 보안 / 암호화 / 파일 관리자.
- 언어: 한국어 / English / 시스템 언어 따르기.
- 화면 모드: 밝게 / 어둡게 / 시스템 따름(창 제목 표시줄도 따라갑니다).
- 날짜 형식과 초 표시, 시작 화면(암호화 창 / 파일 관리자).
- 보안: 화면 캡처 방지(기본 켜짐), 마우스 엔트로피(기본 켜짐), 비밀번호 [보기] 허용, 엄격 모드 등.
- 암호화: 기본 PIM, 압축 등 기본값.
- 파일 관리자: "삭제 전에 확인" 등.
- 분류별 초기화, 전체 초기화, 설정 파일 삭제 버튼이 있습니다.
- 설정 파일에는 비밀번호, 키, 키 파일 경로, 컨테이너 경로를 저장하지 않습니다. 설정이 손상되거나 없으면
  안전한 쪽(화면 캡처 방지 켜짐)으로 시작합니다.
- 보안에 영향을 주는 값(알고리즘, 메모리 256 MiB, 병렬도 4, 7회 덮어쓰기 등)은 설정으로 낮출 수 없습니다.

13. 화면 캡처 방지
------------------
- 기본으로 켜져 있으며 설정 > 보안에서 끄고 켤 수 있습니다. 바꾸면 열려 있는 모든 Shield 창에 바로 적용됩니다.
- 스크린샷, 화면 녹화, 화면 공유 프로그램에 Shield 창이 찍히지 않게 하는 기능입니다. 지원되는 Windows에서는
  창이 캡처에서 제외되고, 그렇지 않으면 검은 화면으로 찍힙니다. 적용하지 못하면 경고가 표시됩니다.
- 한계: 휴대폰 카메라, 하드웨어 캡처 장치, 커널 수준의 악성 프로그램은 막지 못합니다. 완전한 보호가 아닙니다.

14. 마우스 엔트로피와 포터블 실행 파일
--------------------------------------
- 마우스 엔트로피: Shield 창 위의 마우스 움직임을 OS 난수에 보조로 섞어 줍니다. 암호화 탭, 비밀번호·키 교체 탭,
  설정 > 보안에 막대가 보입니다. 모은 정도가 100%가 되면 막대가 초록색으로 바뀌고, 수집된 샘플 수가 막대 아래에
  표시됩니다(막대 위에 마우스를 올려도 보입니다). 보여 주기만 할 뿐 어떤 버튼도 이것을 기다리지 않으며,
  100%가 된다고 암호학적 보증이 생기는 것은 아닙니다. 설정에서 끄면 "꺼짐"으로 표시됩니다.
- 포터블 실행 파일: 설치하지 않고 실행하며 우클릭 메뉴는 등록되지 않습니다. 설정은 실행 파일 옆의
  Shield_data 폴더에 저장됩니다. 사용 후 흔적을 지우려면 그 폴더를 지우세요.
