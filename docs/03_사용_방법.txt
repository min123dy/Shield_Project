SHIELD 1.1 - 사용 방법 및 안전 안내
===================================

이 문서는 Shield 설치 후 시작 메뉴의 "Shield 사용 설명서"에서 다시 열 수 있습니다.
설치 폴더에도 "사용 방법.txt"라는 이름으로 함께 저장됩니다.
앱 안의 '사용법·주의사항' 탭에도 같은 핵심 내용이 있습니다.

0. 설치와 업그레이드
--------------------
- Shield.msi를 실행하면 첫 화면에 주의사항과 사용법이 표시됩니다. 읽고 확인란을 선택한 뒤 [설치]를 누르세요.
- 설치 중에는 진행률 화면이 표시되고, 마지막 화면에서 "지금 Shield 실행"을 선택할 수 있습니다.
- 이전 버전이 설치되어 있으면 자동으로 제거하고 새 버전으로 업그레이드합니다. 기존 .shd 파일은 그대로 열립니다.
- 시작 메뉴 > Shield 에서 실행할 수 있습니다. 실행 중인 창의 작업 표시줄 아이콘을 우클릭해
  "작업 표시줄에 고정"을 선택하면 다음부터 바로 실행할 수 있습니다.

1. 화면 구성
------------
- 위쪽 탭: 암호화 / 복호화 / 비밀번호 변경 / 디스크 정리 / 사용법·주의사항
- 왼쪽 탐색기: 클릭하면 선택, 폴더는 더블클릭으로 열기. 상위·홈·드라이브·새로고침 버튼,
  "파일 열기…"/"폴더 선택…" 버튼, 이름 필터가 있습니다. 파일/폴더를 창에 끌어다 놓아도 됩니다.
- .shd 파일을 고르면 자동으로 복호화 탭, 그 외 항목을 고르면 암호화 탭으로 바뀝니다.
- 오른쪽 화면은 ①②③④ 단계로 나뉘어 있고, 아직 부족한 입력이 주황색 목록으로 표시됩니다.
  모두 채워지면 아래의 큰 시작 버튼이 활성화됩니다.
- 아래쪽 진행 표시줄: 작업 단계(예: 압축 › 암호화 › 검증), 진행률(%), 처리량, 속도, 남은 시간,
  경과 시간, [취소] 버튼이 표시됩니다. 키 유도(Argon2id) 중에는 움직이는 막대로 표시됩니다.
- 작업 중에는 창을 닫을 수 없습니다. 먼저 [취소]를 누르세요. (원본 파쇄·TRIM 단계는 취소 불가)

2. 암호화
---------
1) 암호화할 파일 또는 폴더를 선택합니다.
2) 비밀번호를 입력하고, 확인 칸에 한 번 더 입력합니다. (Tab 키로 다음 칸 이동, "✔ 일치합니다" 확인)
3) PIM은 "권장 기본값 (12)"을 그대로 두면 됩니다.
4) 필요하면 키 파일을 추가하거나 새로 생성합니다.
5) 옵션을 확인하고 [암호화 시작]을 누릅니다.
6) 압축 → 암호화 → 검증이 끝나면 아래쪽에 완료 메시지가 표시됩니다.

- 기본적으로 원본 옆에 "이름.shd"로 저장합니다. 같은 이름이 있으면 "이름 (2).shd"처럼 번호를 붙입니다.
  "저장 위치 직접 선택"을 켜면 저장 대화상자가 열립니다.
- 키 파일 없이 비밀번호만 쓰면 비밀번호는 12자 이상이어야 합니다.
- 검증에 실패하면 결과 파일을 지우고 원본은 그대로 둡니다.
- 폴더 안의 바로가기/심볼릭 링크(정션)는 따라가지 않으며 압축에 포함하지 않습니다.

3. 키 파일 생성 및 사용
-----------------------
- "새 키 파일 생성…"은 운영체제 난수에 마우스 움직임에서 모은 난수를 섞어 128바이트 키 파일을 만듭니다.
- 마우스 엔트로피는 보수적으로 계산합니다. 방향이나 속도가 바뀐 움직임 1회당 최대 1비트만 인정하며,
  1024비트(불규칙한 움직임 1024회 이상)가 모여야 생성 버튼이 활성화됩니다.
  일정한 직선 이동은 계산되지 않으므로 창 위에서 원이나 지그재그로 불규칙하게 움직이세요.
- 마우스 입력만으로 난수 안전성을 얻는 것이 아니라 항상 OS 난수원이 기본으로 사용됩니다.
- 생성된 키 파일은 자동으로 목록에 추가됩니다. 기존 키 파일은 "키 파일 추가…"로 넣습니다.
- 키 파일은 수정하거나 다시 저장하지 마십시오. 1바이트만 바뀌어도 복호화할 수 없습니다.
  암호화 파일과 다른 안전한 위치에 백업하십시오.
- 여러 키 파일을 썼다면 복호화할 때 같은 파일을 모두 넣어야 합니다(순서 무관).

4. PIM
------
- PIM은 비밀번호를 키로 바꾸는 Argon2id 계산(메모리 128 MiB)의 반복 횟수를 정합니다. 반복 횟수 = 3 + PIM.
- 새 파일의 권장 기본값은 PIM 12(반복 15회)입니다. 1.0 버전의 기본값(PIM 0, 반복 3회)보다
  추측 공격 한 번에 드는 비용이 5배 큽니다.
- "직접 지정"으로 0~64를 고를 수 있습니다. 바꿨다면 복호화할 때 같은 값을 넣어야 하므로 꼭 기록하세요.
- 기본값보다 낮은 PIM을 키 파일 없이 쓰려면 비밀번호가 20자 이상이어야 합니다.
- 1.0 버전에서 기본값(PIM 0)으로 만든 파일은 PIM을 기본값 그대로 두면 자동으로 열립니다.
  이 경우 완료 메시지에 안내가 표시되며, '비밀번호 변경'으로 새 기본 PIM을 적용하는 것을 권장합니다.
- 120초 동안 입력이 없으면 입력된 비밀번호가 자동으로 지워집니다.

5. 복호화
---------
1) .shd 파일을 선택합니다(복호화 탭으로 자동 전환).
2) 암호화 때 쓴 비밀번호를 입력합니다.
3) PIM을 바꾸지 않았다면 기본값 그대로 둡니다.
4) 키 파일을 썼다면 모두 추가합니다.
5) [복호화 시작]을 누릅니다. 기본적으로 .shd 파일과 같은 폴더에 풉니다.
   "저장 폴더 직접 선택"을 켜면 폴더를 고를 수 있습니다.

- 원래 파일/폴더 이름으로 복원합니다. 같은 이름이 이미 있으면 덮어쓰지 않고
  "이름 (decrypted).확장자", "이름 (decrypted 2).확장자"처럼 이름을 붙입니다.
- 압축 항목 경로가 대상 폴더를 벗어나거나 장치 이름/드라이브 문자/대체 데이터 스트림을 쓰면 거부합니다.

6. Windows 파일 탐색기 우클릭 메뉴
----------------------------------
- 파일/폴더 우클릭: "Shield로 암호화", .shd 파일 우클릭: "Shield로 복호화"
- Windows 11에서는 "더 많은 옵션 표시" 안에 나타날 수 있습니다.
- 우클릭 메뉴는 Shield를 해당 항목이 선택된 상태로 엽니다. 자동으로 작업을 시작하지는 않습니다.

7. 비밀번호 변경
----------------
1) '비밀번호 변경' 탭에서 .shd 파일을 선택합니다.
2) ② 현재 비밀번호/PIM/키 파일을 입력합니다.
3) ③ 새 비밀번호(두 번), 새 PIM, 새 키 파일을 정합니다.
4) [비밀번호 변경]을 누릅니다.

- 파일 데이터는 그대로 두고 데이터 키만 새 자격 증명으로 다시 봉인하므로 파일 크기와 상관없이 빠릅니다.
- 새 키 슬롯을 기록한 뒤 새 자격 증명으로 다시 열어 같은 데이터 키가 나오는지 확인하고,
  그다음에만 기존 키 슬롯을 7회 덮어써 파기합니다.
- 작업 전 .shd 파일의 백업을 권장합니다.

8. 원본 파쇄 옵션 (암호화 탭 ④)
--------------------------------
"암호화·검증이 끝나면 원본 파쇄"를 켜고 확인란("복구할 수 없음을 이해했습니다")을 선택해야 합니다.
- 덮어쓰기 횟수: HDD 또는 종류를 모르는 디스크 7회, SSD 1회 ("SSD여도 7회 덮어쓰기" 선택 가능)
- 파쇄 후 TRIM 실행 (기본 켜짐): SSD에 삭제된 블록을 알려 줍니다. HDD에서는 건너뜁니다.
- 파쇄 후 드라이브 여유 공간 덮어쓰기 (기본 꺼짐, 선택): 매우 오래 걸립니다.
- 읽기 전용 파일도 파쇄할 수 있도록 속성을 해제한 뒤 덮어씁니다.

중요: 덮어쓰기 횟수만으로 저장장치의 모든 복사본이 물리적으로 제거된다고 보장할 수 없습니다.
SSD의 웨어 레벨링, 예비 영역, 재매핑, 파일시스템 스냅샷, 백업, 클라우드 동기화 등은
별도로 고려해야 합니다. 이 기능을 완전 삭제 보증으로 해석하지 마십시오.

9. 디스크 정리 탭 (Windows)
---------------------------
- 드라이브를 고릅니다(현재 폴더의 드라이브가 기본 선택됨).
- "TRIM 실행" (권장, 빠름): Optimize-Volume -ReTrim으로 여유 공간 전체에 TRIM을 요청합니다.
  관리자 권한이 필요하므로 Windows 확인 창(UAC)이 뜰 수 있습니다. HDD는 지원하지 않습니다.
- "여유 공간 덮어쓰기" (선택): cipher /w로 빈 공간 전체를 3회(00 → FF → 난수) 덮어씁니다.
  수십 분~수 시간이 걸리고 SSD 쓰기 수명을 소모합니다. 취소할 수 있으며, 끝난 뒤 TRIM도 실행할 수 있습니다.
- 두 기능 모두 SSD 내부의 모든 물리 셀을 지운다고 보장하지 않습니다.

10. 중요한 안전 안내
--------------------
- 비밀번호, PIM, 키 파일을 잃어버리면 암호화된 파일을 복호화하지 못합니다.
- 비밀번호와 키 파일은 암호화 파일과 분리해 안전하게 백업하십시오.
- 원본 파쇄를 사용하기 전 반드시 복호화 테스트를 하십시오.
- 중요한 데이터는 암호화 전후 별도 백업을 유지하십시오.
- 메모리 잠금, zeroize, 프로세스 보호는 최선의 노력(best effort)입니다. 같은 사용자 권한의 프로그램이
  Shield의 메모리를 읽거나 코드를 주입하는 것은 막지만, 관리자/커널/물리적 접근까지 차단하지는 못합니다.
  (이 보호 때문에 작업 관리자에서 일반 권한으로 Shield를 강제 종료할 수 없습니다. 창을 닫아 종료하세요.)
- 파일의 외형이 난수처럼 보이도록 설계된 부분은 암호화 사실을 숨긴다는 보장이 아닙니다.
- 히든 볼륨 또는 부인 가능 저장 기능은 구현되어 있지 않습니다.

Shield의 암호화 및 삭제 기능은 중요 데이터에 적용하기 전에 복사본으로 충분히 시험하십시오.
