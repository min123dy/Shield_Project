■ Shield 3.0.0 설치 안내 - 주의사항과 사용법을 꼭 읽어 주세요

이미 Shield(2.1.0, 3.0.0 베타 포함)가 설치되어 있으면 설치 언어와 관계없이 이전 버전을 자동으로 제거하고
3.0.0으로 업그레이드합니다.
3.0은 2.x 컨테이너를 그대로 엽니다. 1.x 형식은 열지 않으므로 1.x 파일은 먼저 1.x로 복호화하세요.

■ 반드시 지켜야 할 주의사항
- 비밀번호, PIM, 키 파일 중 하나라도 잃어버리면 누구도(개발자 포함) 파일을 복호화할 수 없습니다.
- 키 파일은 수정하거나 다시 저장하지 말고, 암호화 파일과 다른 안전한 곳에 백업하세요.
- 덮어쓰기 삭제(원본 파쇄)는 되돌릴 수 없습니다. 처음에는 복사본으로 암호화와 복호화를 모두 시험해 보세요.
- SSD, USB 메모리, 볼륨 섀도 복사본, 클라우드 동기화 폴더에서는 덮어쓰기와 TRIM이 물리적 삭제를 보장하지
  않습니다. Shield는 섀도 복사본을 확인해 알려 주지만 지우지는 않습니다.
- 비밀번호를 바꿔도 이전에 만든 백업본은 이전 비밀번호로 계속 열립니다.
- 메모리 보호와 프로세스 보호는 최선의 노력이며, 같은 사용자 권한의 악성 프로그램이나 관리자, 커널,
  물리적 접근까지 막지는 못합니다.
- 화면 캡처 방지(기본 켜짐)는 스크린샷과 화면 녹화 같은 소프트웨어 캡처만 막습니다.
- 이 설치 파일에는 Authenticode 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
  함께 받은 .sig와 VERIFY.txt로 OpenPGP 서명을 먼저 검증하고, 키 지문을 개발자가 공개한 지문과 비교하세요.
- 업데이트 확인은 기본으로 꺼져 있습니다. 켜면 GitHub에 접속만 하고 식별 정보는 보내지 않으며,
  서명이 맞는 새 버전만 설치 전에 물어본 뒤 설치합니다.

■ 설치되는 것
- shield-gui.exe(창 프로그램)와 shield.exe(명령줄 프로그램). 설치 폴더가 시스템 PATH에 추가되어
  새 명령 창에서 'shield help'를 쓸 수 있습니다.
- 시작 메뉴 바로 가기, 탐색기 우클릭 메뉴(여러 항목 선택 지원), 사용 설명서.

■ 사용법 (요약)
1. 시작 메뉴의 'Shield'는 암호화 창, 'Shield 파일 관리자'는 파일 탐색과 .shd 열기 창입니다.
2. 파일/폴더(여러 개 가능) 우클릭: 'Shield로 암호화' -> 하나로 묶을지 각각 만들지 고릅니다.
   .shd 우클릭: 'Shield로 복호화', 'SHIELD에서 열기'. (Windows 11은 '더 많은 옵션 표시' 안에 있습니다)
3. 비밀번호를 두 번 입력하고 PIM은 권장 기본값(12)을 그대로 둡니다.
4. [암호화 시작]을 누르면 압축, 암호화, 복원 검증이 진행됩니다.
5. 설정 > 보안에서 먼저 설정 비밀번호를 만들면 보안 설정을 바꿀 수 있습니다.

자세한 설명은 각 창의 '사용법' 탭과 시작 메뉴의 'Shield 사용 설명서'에 있습니다.

위 내용을 이해했다면 아래 확인란을 선택한 뒤 [설치]를 누르세요.
