■ Shield 설치 안내 - 주의사항과 사용법을 꼭 읽어 주세요

이미 Shield가 설치되어 있으면 이전 버전을 자동으로 제거하고 새 버전으로 업그레이드합니다.
기존 .shd 파일은 그대로 열 수 있습니다.

■ 반드시 지켜야 할 주의사항
- 비밀번호, PIM, 키 파일 중 하나라도 잃어버리면 누구도(개발자 포함) 파일을 복호화할 수 없습니다.
- 키 파일은 수정하거나 다시 저장하지 말고, 암호화 파일과 다른 안전한 곳에 백업하세요.
- '원본 파쇄'는 되돌릴 수 없습니다. 처음에는 복사본으로 암호화와 복호화를 모두 시험해 보세요.
- SSD는 덮어쓰기나 TRIM을 해도 내부 예비 영역의 사본까지 지워진다고 보장할 수 없습니다.
- 클라우드 동기화, 백업, 볼륨 섀도 복사본에 남은 원본은 Shield가 지우지 않습니다.
- 메모리 보호와 프로세스 보호는 최선의 노력이며, 관리자/커널/물리적 접근까지 막지는 못합니다.

■ 사용법 (요약)
1. 시작 메뉴에서 Shield를 실행하거나, 파일/폴더를 우클릭해 'Shield로 암호화'를 선택합니다.
   (Windows 11은 '더 많은 옵션 표시' 안에 있습니다)
2. 비밀번호를 두 번 입력합니다. PIM은 '권장 기본값'을 그대로 두면 됩니다.
3. [암호화 시작]을 누르면 압축 → 암호화 → 검증이 진행되고 화면 아래에 진행률이 표시됩니다.
4. 복호화는 .shd 파일을 우클릭해 'Shield로 복호화'를 고르거나 앱에서 선택한 뒤 같은 비밀번호로 엽니다.
5. '디스크 정리' 탭에서 TRIM만 빠르게 실행하거나, 필요할 때만 여유 공간 덮어쓰기를 선택할 수 있습니다.
6. 실행 중인 Shield 창은 작업 표시줄 아이콘을 우클릭해 '작업 표시줄에 고정'할 수 있습니다.

자세한 설명은 앱의 '사용법·주의사항' 탭과 시작 메뉴의 'Shield 사용 설명서'에 있습니다.

위 내용을 이해했다면 아래 확인란을 선택한 뒤 [설치]를 누르세요.
