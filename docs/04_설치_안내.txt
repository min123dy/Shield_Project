■ Shield 2.0 설치 안내 - 주의사항과 사용법을 꼭 읽어 주세요

이미 Shield가 설치되어 있으면 이전 버전을 자동으로 제거하고 2.0으로 업그레이드합니다.

■ 1.x 사용자 경고
- Shield 2.0은 1.x에서 만든 .shd 파일을 열지 않습니다 (파일 형식이 바뀜).
- 업그레이드하기 전에 1.x로 모든 .shd 파일을 복호화해 두세요. 2.0 설치 후 다시 암호화하면 됩니다.

■ 반드시 지켜야 할 주의사항
- 비밀번호, PIM, 키 파일 중 하나라도 잃어버리면 누구도(개발자 포함) 파일을 복호화할 수 없습니다.
- 키 파일은 수정하거나 다시 저장하지 말고, 암호화 파일과 다른 안전한 곳에 백업하세요.
- '원본 파쇄'는 되돌릴 수 없습니다. 처음에는 복사본으로 암호화와 복호화를 모두 시험해 보세요.
- SSD, USB 메모리, 볼륨 섀도 복사본, 클라우드 동기화 폴더에서는 물리적 삭제를 보장할 수 없습니다.
- 비밀번호를 바꿔도 이전에 만든 백업본은 이전 비밀번호로 계속 열립니다.
- 메모리 보호와 프로세스 보호는 최선의 노력이며, 같은 사용자 권한의 악성 프로그램이나 관리자, 커널,
  물리적 접근까지 막지는 못합니다.
- 이 설치 파일에는 Authenticode 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
  배포 파일과 함께 받은 .sig와 VERIFY.txt로 GPG 서명을 먼저 검증하세요.

■ 사용법 (요약)
1. 시작 메뉴의 'Shield'는 암호화 창, 'Shield 파일 관리자'는 파일 탐색과 .shd 열기 창입니다.
2. 파일/폴더 우클릭: 'Shield로 암호화'. .shd 우클릭: 'Shield로 복호화', 'SHIELD에서 열기'.
   (Windows 11은 '더 많은 옵션 표시' 안에 있습니다)
3. 비밀번호를 두 번 입력하고 PIM은 권장 기본값(12)을 그대로 둡니다.
4. [암호화 시작]을 누르면 압축, 암호화, 복원 검증이 진행됩니다.
5. 'SHIELD에서 열기'로 내용을 보고 일부만 꺼내거나 파일을 추가할 수 있습니다.

자세한 설명은 각 창의 '사용법' 탭과 시작 메뉴의 'Shield 사용 설명서'에 있습니다.
